> **The only open-source Medical AI that computes P(Y|do(X)) — interventional causal inference — instead of mere correlations.**

```
📦 9-Phase Architecture
├── Phase 0-2  → Data Engineering: 5,326 PubMed papers → SQLite + FAISS + BM25 Hybrid RAG
├── Phase 3    → QLoRA Fine-Tuning: Mistral-7B (7.24B params, 4-bit NF4, 0.23% trainable)
├── Phase 4    → 5-Agent MAS: Router → Research → Causal Extraction → Fact-Check → Synthesis
├── Phase 5    → Causal Engine: Pearl do-calculus, Graph Surgery, ATE/ITE, Counterfactuals
├── Phase 6    → Biomedical KG: 1,129 nodes, 607 directed edges, Quality Score 89.8/100
├── Phase 7    → Uncertainty QA: Isotonic Calibration (ECE=0.0082), MC Dropout, Ensemble
├── Phase 8    → Deployment: FastAPI + Streamlit + Redis + NGINX + Prometheus + Grafana
└── Phase 9    → MLOps: KS-Drift Detection (KS=0.285) + A/B Testing (+15.56% lift, p=0.034)
```
